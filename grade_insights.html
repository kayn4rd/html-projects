    Importing exam results

    • Use a CSV or Excel file with one row per student. Recommended columns: Student ID, Student Name, Section, Score. Column headers are detected automatically; you can correct the mapping before importing.
    • If your Excel workbook has one sheet per section and no Section column, choose All sheets and map Section to Use sheet name.
    • Choose Replace to start fresh or Append to add rows to the existing data.
    • Set the Maximum exam score first (default 100). Scores below 0 or above the maximum are flagged as errors.
    • Records can be edited directly in the Data tab; every chart and statistic updates immediately.

    Validation rules

    • Excluded from analysis: missing section, missing or non-numeric score, score outside 0–max, and (when the checkbox is on) repeated student IDs – the first occurrence is kept. If a row has no ID, the name + section combination is used.
    • Warnings only: missing student ID or name.

    Using the tabs

    • Overview – key observations, histogram preview, full statistics table.
    • Distribution – histogram with optional normal curve, frequency tables, normality screening.
    • Section Comparison – ranking, bar charts, box plots, overlaid curves, and an optional ANOVA kept separate from the descriptive results.
    • Student-Level Analysis – editable performance categories and a sortable student list with percentile, z-score and outlier flag.
    • Use the Section view selector to focus the Overview, Distribution and Student tabs on one section. Print / Save as PDF opens the browser print dialog (choose “Save as PDF”).

    Methods and thresholds

    • Quartiles: linear interpolation (Excel QUARTILE.INC / R type 7). Mode: all tied values are listed; “None” if every score is unique.
    • Standard deviation, variance, CV and z-scores follow the Sample/Population setting. CV = SD ÷ mean × 100.
    • Skewness: |g| < 0.5 is called approximately symmetric; otherwise positively (tail toward high scores) or negatively skewed.
    • Dispersion wording: CV < 10% tightly clustered, 10–20% moderately spread, ≥ 20% widely dispersed.
    • Normality screening (n ≥ 20): |skewness| < 0.5, |excess kurtosis| < 1, and the share within ±1 SD / ±2 SD close to 68% (±10 pts) / 95% (±5 pts). This is a descriptive screen, not a formal test.
    • A section “stands out” if its passing rate is ≥ 10 points below the all-section rate or under 50%; its SD is ≥ 1.25× the average section SD; or its mean is more than half an overall SD below the overall mean. Sections with n < 10 are marked as small samples.
    • Descriptive vs inferential: everything except the ANOVA panel describes the uploaded scores only. The ANOVA panel tests whether differences between section means are larger than expected by chance under its assumptions; it does not say which sections differ or why.
    • Observations never assert causes. They point to where to look (e.g. which section or score range) rather than explain why.
